# Folder Avatar

Taruh 2 file gambar di sini dengan nama PERSIS seperti ini:

- `male.png`   — avatar untuk pilihan "Laki-laki"
- `female.png` — avatar untuk pilihan "Perempuan"

transparan) atau JPG.

halaman Profile Form — tidak perlu ubah kode apa pun.
